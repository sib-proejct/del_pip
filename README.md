# PiP 속성 제거

확장 프로그램 아이콘을 클릭하면 현재 페이지의 모든 접근 가능한 동영상에서 `disablepictureinpicture` 속성을 제거합니다. 작은 별도 창(PiP)을 여는 동작은 크롬 또는 플레이어 메뉴에서 직접 실행합니다.

## 설치

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더(`/Users/jaehyunpark/repo/del_pip`)를 선택합니다.
5. 크롬의 확장 프로그램 메뉴에서 **PiP 속성 제거**를 고정하면 편리합니다.

## 사용

1. 동영상 페이지에서 확장 프로그램 아이콘을 클릭합니다.
2. `ON` 배지가 표시되면 속성 제거와 감시가 활성화되었습니다. 동영상이 없어도 이후 추가되는 동영상을 감시합니다.
3. 기존 크롬 또는 플레이어의 PiP 기능을 실행합니다. 일부 동영상에서는 우클릭 메뉴를 두 번 열어 크롬 기본 동영상 메뉴에 접근할 수 있습니다.

클릭 후 추가되는 동영상과 다시 설정되는 속성도 처리합니다. 같은 페이지에서 반복 클릭해도 감시자가 중복 생성되지 않습니다. 새로고침하거나 다른 페이지로 이동하면 다시 클릭하세요. 기능을 중지하려면 페이지를 새로고침하세요. 다른 확장 프로그램 페이지, 크롬 내부 페이지 등에서는 실행되지 않으며 `!`로 안내합니다.

새 문서가 로드되면 배지와 툴팁을 초기화합니다. 사이트가 속성을 계속 복구할 때 페이지가 멈추지 않도록 변경 처리를 약 100ms 단위로 모으고, 동영상마다 5초 안에 최대 5회 제거한 뒤 다음 충돌부터 30초 동안 재시도를 쉽니다. 쉬는 동안에는 제한 속성이 남을 수 있습니다. `ON`은 감시 활성화를 뜻하며 모든 영상의 제한 해제를 보장하지 않습니다.

코드 업데이트 후에는 `chrome://extensions`에서 이 확장 프로그램의 새로고침 버튼을 누르고, 동영상 페이지도 새로고침한 뒤 다시 실행하세요.

## 적용 범위

- 일반 페이지, 접근 권한이 있는 iframe, 열린 Shadow DOM을 처리합니다. 클릭 후 만들어진 열린 Shadow DOM은 최대 약 2초 뒤 처리됩니다. 백그라운드 탭에서는 이 주기적 탐색을 쉬고, 다시 표시되면 즉시 탐색합니다.
- 외부 출처 iframe은 `activeTab`만으로 접근하지 못할 수 있습니다. 클릭 후 새로 로드된 iframe에는 다시 클릭해야 합니다. 닫힌 Shadow DOM에는 접근하지 않습니다.
- 속성 제거는 PiP 실행을 보장하지 않습니다. 브라우저 지원, 영상 상태, 사이트의 Permissions Policy 등 별도 제한은 그대로 적용됩니다.
- 요청 권한은 `activeTab`, `scripting`입니다. 외부 통신 및 사용자 정보 수집 기능은 없습니다.
- 페이지와 분리된 실행 환경을 사용하지만, 페이지는 DOM 속성의 삭제를 관찰할 수 있습니다. 실행 사실을 감지할 수 없도록 숨기는 기능은 제공하지 않습니다.

## 검증

`node --test tests/*.test.cjs`로 자동 검증을 실행합니다. 실제 크롬 검증은 `tests/manual.html`을 로컬 웹 서버로 열어 진행합니다. 예: 이 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000/tests/manual.html` 방문.
